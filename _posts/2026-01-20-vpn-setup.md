# Setting Up VPNs on Windows ARM64

I began to use `Windows for ARM` Since Mar. 2025, and most things work smoothly without and difference with x86 machines. Most Windoes apps have ARM version now, and the x86 emulator runs well for those don't have ARM support. However seems the emulator has some problem with VPNs?

I'll post my personal solutions to VPN issues (and perhaps other ARM support problems) here.

## Clash

## iNodeClient by H3C

Used in the computational resource rental service by `China Telcomm`. 

- install iNodeClient Linux-ARM64 version on WSL
- problem of running iNode on WSL: Auth setup

    ```bash
    cd iNodeClient
    sudo ./AuthenMngService
    ```
- do not forget to set network mode as `mirror` at `C:\Users\$username\.wslconfig`

    ```
    [wsl2]
    networkingMode=mirrored
    dnsTunneling=false
    firewall=false
    localhostForwarding=true
    ```

- set a proxy from WSL back to Windows with SSH

    ```bash
    ssh -i "~/.ssh/id_ed25519" -vvv -D 0.0.0.0:1080 -N 127.0.0.1
    ```
    and allow SSH access of your own public key to localhost
